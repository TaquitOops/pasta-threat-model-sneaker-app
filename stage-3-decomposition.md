# Etapa III: Descomposición de la Aplicación

## Diagrama de Flujo de Datos (DFD)
[cite_start]Este análisis representa un proceso individual de la aplicación enfocado en la interacción del usuario con el catálogo[cite: 3, 8].

### Componentes del Flujo
* [cite_start]**Actor (Entidad Externa):** Usuario[cite: 4].
* [cite_start]**Proceso:** Búsqueda de productos (Product search)[cite: 6, 7].
* [cite_start]**Almacén de Datos:** Base de datos (Database)[cite: 5].

### Descripción del Flujo
1. [cite_start]**Petición del Usuario:** El usuario inicia una búsqueda de sneakers disponibles para la venta[cite: 9].
2. [cite_start]**Consulta al Inventario:** El proceso de búsqueda consulta la base de datos para obtener información actualizada[cite: 10].
3. [cite_start]**Respuesta al Usuario:** Se muestran al usuario los listados del inventario de sneakers actual[cite: 10].
